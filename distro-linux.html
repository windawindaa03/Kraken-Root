PETA EKOSISTEM

Garis Keturunan & Ragam Distribusi Linux

Setiap distro meracik Kernel Linux bersama perangkat lunak GNU, Desktop Environment, dan manajer paket tertentu untuk profil pengguna yang spesifik.

Tiga Pilar Garis Keturunan Utama

KELUARGA DEBIAN Format: .deb

Debian / Ubuntu Lineage

Ekosistem paling luas dengan manajer paket apt. Menjadi basis bagi Ubuntu, Linux Mint, Pop!_OS, dan Kali Linux.

Karakter: Stabilitas tinggi, dukungan perangkat keras luas.
KELUARGA RED HAT Format: .rpm

Fedora / RHEL Lineage

Standar server enterprise dan infrastruktur perbankan menggunakan manajer paket dnf serta keamanan SELinux.

Karakter: Adopsi teknologi upstream dan container modern.
ARCH pacman

Rolling Release

Perakitan sistem modular dengan pacman dan repositori komunitas AUR.

Karakter: Pembaruan berkelanjutan tanpa rilis versi mayor.

Katalog Distro Populer

Saring distribusi berdasarkan profil penggunaan dan spesifikasi perangkat keras

KONSEP INTI

Package Manager: Jantung Setiap Distro

Cara Anda menginstal software adalah perbedaan paling praktis antar keluarga distro.

Keluarga Debian / Ubuntu

APT — Advanced Package Tool

Manajer paket berbasis repositori .deb. Unduh, verifikasi, dan instalasi software hanya dengan satu baris perintah.

# Instal software
sudo apt install nginx
# Update semua paket
sudo apt update && apt upgrade
Keluarga Fedora / RHEL

DNF — Dandified YUM

Penerus yum dengan resolusi dependensi lebih cerdas. Format paket .rpm adalah standar enterprise Linux.

# Instal software
sudo dnf install nginx
# Update sistem
sudo dnf upgrade --refresh
Keluarga Arch

Pacman + AUR

Paket dikompilasi dari sumber. AUR (Arch User Repository) menyediakan puluhan ribu paket komunitas yang tidak ada di repo resmi.

# Instal software
sudo pacman -S nginx
# Update sistem
sudo pacman -Syu
INSIGHT PENTING

Meski package manager berbeda-beda, perintah shell POSIX (ls, cd, mkdir, cat, rm) bekerja identik di semua distro. Ini karena semua menggunakan Kernel Linux yang sama dan standar POSIX yang universal.

LAPISAN ANTARMUKA

Desktop Environment: GUI Linux

Linux memisahkan kernel dari antarmuka grafis — Anda bebas memilih tampilan yang paling sesuai.

GNOME

Modern dan minimalis. Default di Ubuntu, Fedora, Debian. Cocok untuk layar HiDPI dan touchscreen.

RAM idle: ~600MB
KDE Plasma

Sangat bisa dikustomisasi. Tampilan mirip Windows. Digunakan oleh Kubuntu dan openSUSE.

RAM idle: ~400MB
XFCE

Ringan dan stabil. Pilihan utama Kali Linux dan Xubuntu untuk hardware lama atau server dengan GUI.

RAM idle: ~220MB
Tanpa DE (Headless)

Server dan cloud tidak membutuhkan GUI sama sekali. Semua dioperasikan via SSH dan terminal.

RAM idle: ~80MB
PANDUAN PRAKTIS

Bagaimana Cara Memilih Distro yang Tepat?

01
Tentukan Tujuan Utama

Desktop harian → Ubuntu/Mint. Developer → Fedora. Server → Debian/RHEL. Security research → Kali. PC jadul → Lubuntu.

02
Periksa Spesifikasi Hardware

RAM < 2GB → pilih Lubuntu atau antiX. RAM 4GB+ → semua distro mainstream berjalan nyaman.

03
Pertimbangkan Siklus Rilis

Ubuntu LTS: 5 tahun dukungan, stabil. Fedora: 13 bulan, selalu baru. Arch: rolling, selalu terbaru tapi perlu perawatan.

04
Coba Dulu via Live USB

Semua distro bisa dijalankan langsung dari flashdisk tanpa instalasi. Coba 2–3 distro sebelum memutuskan.

Transisi ke Modul 04

Standar Perintah Lintas Distribusi

Meski manajer paketnya berbeda (apt, dnf, pacman), seluruh distro berbagi sintaks Shell POSIX yang identik (cd, ls, pwd, mkdir, touch, cat, rm). Praktikkan langsung di Modul 04.
